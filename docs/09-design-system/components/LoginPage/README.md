Contoh layar Login (SCR-001) lewat OIDC.

## Komposisi

Satu kartu di tengah: nama aplikasi (teks, belum ada logo), satu kalimat penjelas, tombol utama "Masuk dengan akun perusahaan", dan teks bantu untuk masalah akses.

## Aturan

- Autentikasi dikelola penyedia identitas OIDC; layar ini tidak memiliki kolom kata sandi sendiri.
- Pesan error spesifik tetapi tidak membocorkan keberadaan akun: "Akses ditolak. Hubungi administrator bila Anda seharusnya memiliki akses."
- Sesi berakhir ditampilkan sebagai pesan di layar ini, bukan sebagai halaman kosong.
- Fokus awal pada tombol masuk; seluruh layar dapat dioperasikan dengan keyboard.
- Tema mengikuti preferensi sistem, dengan kontras sama di light dan dark.

Halaman ini memakai data ilustrasi.
